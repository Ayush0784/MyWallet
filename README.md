# 💼 MyWallet

![Java](https://img.shields.io/badge/Java-100%25-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)
![Maven](https://img.shields.io/badge/Maven-Build-C71A36?style=for-the-badge&logo=apachemaven&logoColor=white)

MyWallet is a robust transaction reporting application built in Java. It allows users to track expenses, generate structured spending summaries, and natively export financial reports.

## ✨ Key Features

* **Comprehensive Expense Tracking:** Easily record and categorize daily transactions and spending habits.
* **Native Currency Formatting:** Financial values and user interface components are optimized and formatted using Indian Rupees (₹).
* **Automated PDF Exports:** Generate high-quality, formatted spending report PDFs directly from the application utilizing the iText library.
* **Maven-Driven Architecture:** Clean dependency management and build processes handled via Maven.

## 🛠️ Technology Stack

* **Language:** Java[cite: 9]
* **Build Tool:** Maven (`pom.xml`)[cite: 9]
* **Document Generation:** iText (PDF Export)
* **UI Framework:** Java Swing / AWT (Custom Gradient & Rounded Panels)
